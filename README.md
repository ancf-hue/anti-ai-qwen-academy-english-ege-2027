# анти-ии квен академия английский язык егэ-2027

Бесплатный социальный офлайн-проект — тренажёр ЕГЭ-2027 по английскому языку по официальной демоверсии ФИПИ.

> 🌐 **Онлайн-версия:** [ancf-hue.github.io/anti-ai-qwen-academy-english-ege-2027](https://ancf-hue.github.io/anti-ai-qwen-academy-english-ege-2027/)

## 📌 О проекте

Тренажёр полностью соответствует **демоверсии, спецификации и кодификатору ФИПИ 2027**. Работает в любом браузере без установки, без интернета и без регистрации. Все ответы проверяются локально — ваши данные никуда не отправляются.

### Что внутри

- **42 задания** (38 письменных + 4 устных)
- **82 первичных балла**
- **190 минут** — письменная часть
- **17 минут** — устная часть
- Двуязычный интерфейс **RU / EN**
- Встроенный таймер экзамена (пресеты: 190 / 30 / 60 / 17 минут)
- Чек-лист подготовки из 21 пункта
- План подготовки на 25 дней
- Приблизительная самопроверка развёрнутых ответов (37–42)

## 📚 Структура тренажёра

| Раздел | Задания | Баллы |
|---|---|---|
| Аудирование | 1–9 | 12 |
| Чтение | 10–18 | 12 |
| Грамматика и лексика | 19–36 | 18 |
| Письменная речь | 37–38 | 20 |
| Устная часть | 39–42 | 20 |
| **Итого** | **42** | **82** |

## 🎧 Аудиофайлы

Для полноценной работы положите рядом с `index.html` два файла:

- `audio-en.mp3` — запись для заданий 1–9 (аудирование)
- `audio-en-oral.mp3` — запись для устного задания 3 (интервью)

Файлы можно взять из официальных материалов ФИПИ или записать самостоятельно.
